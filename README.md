2D Top-Down Survival Game

A 2D top-down survival game developed using Unity and C#, where the player must survive against continuously spawning enemies while managing health and using projectiles for combat.

🎮 Game Overview

The player controls a blue capsule character in a top-down environment. Green enemy characters continuously spawn and chase the player. The objective is to survive as long as possible, avoid enemy collisions, and achieve a high score.

✨ Features

Player Movement: Control the player character in a 2D environment.

Enemy AI: Enemies spawn dynamically and follow the player.

Enemy Spawning: Multiple enemies spawn during gameplay.

Health System: Player health decreases when enemies collide with the player.

Power-ups: Health power-ups help restore player health.

Projectile System: Projectile-based combat mechanics.

Score System: Tracks survival time and player score.

Pause System: Pause and resume gameplay.
